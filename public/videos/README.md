# Vidéos du site

## Vidéo actuelle du hero

`public/videos/hero.mp4` — « Serving juice in a glass with some oranges »
(source : [Mixkit](https://mixkit.co), clip **10428-720**, sous **licence
Mixkit Free** : gratuite pour un usage commercial, attribution non requise).

Elle se lance automatiquement en fond du hero, en boucle et silencieuse
(obligatoire pour l'autoplay des navigateurs). Pendant le chargement, le
navigateur affiche le poster dégradé `public/images/hero-poster.svg`.

## Remplacer par vos propres images du restaurant

Écrasez simplement le fichier **`public/videos/hero.mp4`** avec votre propre
vidéo — aucune modification de code nécessaire. Conseils de prise de vue :

| Critère    | Recommandation                                              |
| ---------- | ----------------------------------------------------------- |
| Format     | MP4 (H.264)                                                 |
| Durée      | 10–20 s, tournée ou montée pour boucler                     |
| Contenu    | Burger, sandwich, ustensiles, jus de bissap pris sur le lieu |
| Poids      | ≤ 8 Mo (~720p suffit : la vidéo est atténuée sous le texte)  |
| Son        | Sans importance : lecture uniquement en muet dans le hero    |
